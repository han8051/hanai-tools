﻿HANAI Tools Plus 사용설명서
==========================

HANAI Tools Plus — 더해진 기능
====================================
  · HANAI Zip  : 7Z 압축 풀기 (LZMA·LZMA2·BZip2·Deflate·BCJ 필터, AES-256 암호,
                 파일 목록까지 암호화된 7Z 포함). 7Z는 풀기 전용이며 저장하면 ZIP/TAR.GZ가 됩니다.
                 7Z의 PPMd 방식, RAR·ALZ·EGG는 아직 지원하지 않습니다.
  · HANAI Song : 음정(키) 조절 ±12반음 (속도는 그대로) — 효과 탭, 단축키 , / .
                 음악 편집·녹음 결과를 MP3(128~320kbps)로 저장, 제목·가수·앨범아트 태그 포함
  · HANAI PDF  : 문자 인식(OCR) — 스캔 PDF를 '검색 가능한 PDF'로 만들기, 글자만 뽑기
  · HANAI Capture / HANAI View : 그림·사진 속 글자 추출(OCR)
  · HANAI Player : 음정(키) 조절 ±12반음 (속도는 그대로) — 소리 탭, 단축키 Ctrl+↑ / Ctrl+↓
                 음성 추출을 MP3(128~320kbps)로 저장, 캡처한 화면에서 글자 추출(OCR)
  · HANAI Photo  : AI 배경 지우기(사람·물건만 남기기), 아이폰 HEIC 사진 열기·JPG로 바꾸기,
                 사진 속 글자 추출(OCR)

  ※ 인터넷이 필요한 경우
    - MP3 저장: 처음 한 번 인코더(약 150KB)를 받아 브라우저에 저장 → 이후 인터넷 없이 동작
    - 문자 인식: 쓸 때마다 인식 엔진을 인터넷에서 받고, 언어 데이터는 처음 한 번 받아 저장
    - HEIC 열기: 처음 한 번 변환 부품(약 1MB)을 받아 저장 / AI 배경 지우기: 쓸 때 인식 모델(수십 MB)을 받음
    - 받는 곳: cdn.jsdelivr.net (공개 오픈 소스 배포처). 내 파일은 전송되지 않습니다.
    - 7Z 풀기와 음정 조절(HANAI Song·HANAI Player)은 인터넷 없이 바로 동작합니다.


알툴즈처럼 쓰는 생활 필수 프로그램 8종을 브라우저용으로 만든 모음입니다.
설치할 필요가 없고, 파일은 모두 내 컴퓨터 안에서만 처리됩니다(인터넷 전송 없음).

■ 시작하기
  1) 이 폴더(HANAI Tools)의 「HANAI Tools.html」을 더블클릭하면 시작 화면이 열립니다.
  2) 각 프로그램 파일(HANAI Song.html, HANAI Zip.html …)을 직접 더블클릭해도 됩니다.
  3) Chrome 또는 Microsoft Edge 최신 버전을 권장합니다.
     (기본 브라우저가 다르면: 파일 오른쪽 클릭 → 연결 프로그램 → Chrome/Edge)
  4) lib 폴더는 모든 프로그램이 함께 쓰는 부품입니다. 지우거나 따로 옮기지 마세요.
  5) 각 프로그램 안에서 F1을 누르면 도움말과 단축키가 나옵니다.

1. HANAI Song (음악 플레이어)
────────────────────────────────────────
  · 파일/폴더 열기, 끌어다 놓기 — MP3, M4A, FLAC, OGG, OPUS, WAV
  · 여러 재생목록(탭), 검색, 정렬, 끌어서 순서 바꾸기, 중복 제거, M3U 저장
  · 재생목록·즐겨찾기·재생 횟수를 브라우저에 기억 (다음에 열어도 그대로)
  · 라이브러리: 모든 곡을 아티스트·앨범·장르·연도·폴더별로 보기,
    즐겨찾기(★)·많이 들은 곡·최근 재생·최근 추가·가사 없는 곡 모아 보기
  · 태그·앨범아트 읽기 (ID3v1/v2, FLAC, MP4, OGG), 한글 깨짐 자동 처리
  · 싱크 가사: 같은 이름의 .lrc 자동 연결, MP3 안의 SYLT/USLT 가사 표시
  · 인터넷 가사 찾기: 공개 가사 데이터베이스(LRCLIB)에서 싱크 가사 검색
    (가사가 없는 곡은 자동으로 찾기 — 설정에서 끌 수 있음, 제목·가수·길이만 전송)
  · 노래방처럼 지금 부르는 줄이 시간에 맞춰 색이 채워짐
  · 데스크톱 가사창(L): 항상 위에 떠 있는 가사 창 — 1/2/3줄, 좌우 번갈아 두 줄,
    글꼴·크기·색(부른 부분/부르기 전)·배경·테두리 설정
  · 항상 위 미니 플레이어, 작은 화면 모드(Ctrl+M)
  · 가사 싱크 편집기: 노래를 들으며 Enter로 시간 찍기 → LRC 저장 / MP3에 저장
  · 태그 편집기(한 곡) + 여러 곡 일괄 편집, 파일 이름 → 태그, 태그 → 파일 이름
  · 10밴드 이퀄라이저 + 프리셋 16종 + 사용자 프리셋 + 주파수 응답 그래프
  · 음장 효과: 베이스 부스트, 3D 서라운드, 공간감, 보컬 제거(노래방), 모노
  · 크로스페이드(곡과 곡을 겹쳐 넘기기), 페이드, ReplayGain, 볼륨 평준화
  · 재생 속도(음정 유지), 구간 반복(A-B), 예약 종료, 긴 곡 이어 듣기
  · 음악 편집: 파형 보며 구간 자르기, 벨소리 만들기, 페이드, WAV 변환
  · 녹음기: 마이크 또는 재생 중인 소리 녹음 (WebM/WAV)
  · 시각화 4종, 스킨 5종
  · 한계: MP3로 변환 저장, 가사 서버에 가사 올리기는 지원하지 않습니다.

2. HANAI Zip (압축 프로그램)
────────────────────────────────────────
  · 열기: ZIP(ZIP64 포함), JAR/APK/DOCX 등 ZIP 계열, TAR, TAR.GZ(TGZ), GZ
  · 한글 파일 이름 깨짐 자동 처리(CP949), 상태 표시줄에서 인코딩 직접 선택
  · 알아서 풀기: 압축 파일 이름의 폴더를 만들어 한 번에 풀기
  · 압축 풀기: 선택 항목만/전체, 폴더 구조 유지, 덮어쓰기 옵션
  · 새로 압축: ZIP/TAR.GZ/TAR, 압축 수준 4단계, 설명(주석)
  · 암호: AES-256(안전) 또는 ZipCrypto(윈도우 탐색기 호환) — 걸린 암호도 풀기
  · 압축 파일 편집: 파일·폴더 추가, 삭제, 이름 바꾸기, 새 폴더 → 저장
  · 미리 보기(그림·글·음악·동영상·PDF), 압축 테스트, 형식 변환, 정보/속성
  · 열 수 없는 형식: RAR, 7Z, ALZ, EGG (브라우저 한계)

3. HANAI View (이미지 뷰어·편집기)
────────────────────────────────────────
  · 폴더 열기 → 하위 폴더 트리 + 썸네일, 정렬, 썸네일 크기 조절, 찾기
  · 정보 창: 해상도, 파일 정보, EXIF(카메라·렌즈·노출·ISO·GPS), 히스토그램
  · 크게 보기: 휠 확대/축소, 끌어서 이동, 회전·반전, 전체 화면, 필름 스트립
  · 슬라이드 쇼(F5): 넘김 간격·반복 설정
  · 편집(E): 자르기(비율 고정), 크기, 회전/수평 맞추기, 자동 보정, 밝기·대비·
    채도·감마·색조·색온도·선명도, 효과 10종+비네팅/엠보스/노이즈,
    모자이크/흐림/검게 칠하기(영역·붓), 글자(외곽선·그림자), 펜/형광펜,
    도형, 테두리(폴라로이드) — 실행 취소/다시 실행
  · 폴더로 연 사진은 원본에 바로 저장, 회전·이름 바꾸기·삭제도 원본에 반영
  · 일괄 변환: 형식·품질·크기·이름 규칙·회전·워터마크·보정을 한 번에
  · 사진 합치기(가로/세로/바둑판), GIF 만들기, 클립보드 복사/붙여넣기, 인쇄

4. HANAI PDF (PDF 뷰어·편집기)
────────────────────────────────────────
  · 보기: 썸네일, 연속 스크롤, 너비/쪽 맞춤, 글자 선택·복사, 본문 찾기(Ctrl+F)
  · 암호 걸린 PDF 열기 (암호 입력)
  · 페이지 정리: 끌어서 순서 바꾸기, 회전, 삭제, 복제, 빈 쪽·다른 PDF·이미지 삽입
  · 합치기, 나누기(쪽별/N쪽씩/범위/반), 쪽 추출
  · 이미지 → PDF(A4 맞춤·여백), PDF → 이미지(JPG/PNG/WEBP, 72~300dpi), 텍스트 추출
  · 주석: 펜, 형광펜, 글상자, 사각형, 원, 화살표, 선, 흰색 지우기, 이미지
  · 서명(손글씨/이름 입력, 저장해 두고 재사용), 도장 만들기(승인·확인 등)
  · 워터마크(한글 가능, 투명도·각도·반복), 쪽 번호(모양·위치·양면)
  · 압축(기본/강한/최대), 문서 정보(제목·작성자 등) 편집, 인쇄
  · 실행 취소/다시 실행
  · 한계: 새 암호 걸기, 문자 인식(OCR), 원래 글자 직접 수정은 지원하지 않습니다.
          보호된 PDF를 편집해 저장하면 해당 쪽은 고화질 이미지로 다시 만들어집니다.

5. HANAI Capture (화면 캡처)
────────────────────────────────────────
  · 영역 지정 / 전체 화면 / 창·탭 / 지연(3·5·10초) 캡처
    - 처음에 브라우저가 공유할 화면을 묻습니다. 고른 화면은 계속 유지됩니다.
    - 영역 지정: 돋보기(픽셀 좌표·색), 방향키로 1px 조절, Enter = 전체
  · Win+Shift+S로 찍고 Ctrl+V로 붙여 편집하는 방법도 지원
  · 편집: 펜, 형광펜, 직선, 화살표, 사각형, 원, 글자(말풍선), 번호 ①②③,
    모자이크, 흐림, 강조(나머지 어둡게), 자르기, 여백 자동 자르기, 스포이트,
    그림자/선 테두리, 둥근 모서리, 회전·반전·크기 조절
  · 저장(PNG/JPG/WEBP/PDF), 클립보드 복사(캡처 시 자동), 인쇄, 화면 색 추출
  · 캡처 기록 최근 40개 보관
  · 한계: 브라우저 보안상 Print Screen 같은 전역 단축키, 스크롤 캡처는 불가

6. HANAI Player (동영상 플레이어)
────────────────────────────────────────
  · 열기: 파일·폴더 열기, 끌어다 놓기(Shift: 재생목록에 추가), 최근 파일, 지난 재생목록
  · 재생 형식: MP4·M4V·MOV(H.264/AAC), WebM(VP8·VP9·AV1), MKV, MP3·M4A·FLAC·WAV·Opus
  · 이어 보기: 파일마다 마지막 위치를 기억 (묻기/자동/끄기)
  · 재생목록: 추가·삭제·끌어서 순서 바꾸기·정렬·중복 지우기, 반복(한 개/전체)·무작위,
    다음 파일 자동 재생, M3U·M3U8·PLS 읽기/저장
  · 탐색: ←→ 5초, Ctrl+←→ 30초, Shift+←→ 1초, 숫자 1~9, 탐색 막대 미리보기 그림
  · 배속 0.1~4배(음정 유지) — Z 기본, X 느리게, C 빠르게
  · 프레임 단위 이동 D / F, 구간 반복 [ ] \, 책갈피(B), 챕터(MP4·MKV) 표시·이동
  · 화면: 전체 화면(Enter·더블클릭), 미니 모드(Ctrl+M), 화면 속 화면(P),
    화면 비율 9가지, 확대·이동, 90° 회전·좌우/상하 반전, 잘라내기(검은 띠 자동 찾기)
  · 영상 조정: 밝기·대비·채도·색조·감마·선명도 + 프리셋
  · 자막: SMI(여러 언어)·SRT·VTT·ASS/SSA, UTF-8·CP949 자동 판별, 같은 이름 자막 자동 연결,
    이중 자막, 싱크 조절(< > 0.5초, 직접 입력), 글꼴·크기·색·외곽선·그림자·배경·위치,
    ASS 스타일·위치·색 표시, MKV·MP4 내장 텍스트 자막 꺼내기, 싱크 맞춘 자막 SRT/SMI 저장
  · 소리: 볼륨 0~200%(증폭), 10밴드 이퀄라이저+프리셋, 음량 평준화,
    채널(스테레오/모노/왼쪽/오른쪽/좌우 바꾸기), 음성 싱크 ±5초(Ctrl+, / Ctrl+.)
  · 캡처: Ctrl+E 원본 해상도 캡처(PNG/JPG/WebP, 저장 폴더 지정), 클립보드 복사,
    연속 캡처(여러 장 ZIP / 한 장에 모은 미리보기 이미지), 구간 GIF 만들기,
    구간 동영상 잘라 저장(WebM, 실제 시간만큼 걸림), 음성 추출(WAV)
  · 파일 정보(코덱·해상도·프레임레이트·비트레이트·음성·자막·챕터), Tab 재생 정보, 스킨 5종
  · 한계: AVI·WMV·FLV·RMVB·MPG·TS, AC3·DTS 음성, 일부 HEVC는 브라우저가 재생하지 못합니다.
    음성 트랙 바꾸기는 브라우저가 지원할 때만 됩니다. "항상 위" 창과 탐색기 파일 연결은 불가.
    그림 자막(PGS·VobSub)은 지원하지 않습니다.

7. HANAI Photo (사진 꾸미기·편집 — 포토스케이프처럼)

    - 자동 레벨·자동 대비·역광 보정·선명하게·뽀샤시, 밝기·대비·채도·색조·색온도·감마

    - 사물: 글자(외곽선·그림자·배경), 말풍선 4종(꼬리 끌기), 도형 8종, 스티커(이모지), 아이콘, 사진 넣기

    - 도구: 적목 제거, 잡티 제거, 복제 도장, 모자이크·흐림·흑백 붓, 원래대로 붓(컬러 포인트), 지우개, 마법봉 배경 지우기, 스포이트
    - 실행 취소/다시 실행, 원본 비교, 원본에 덮어쓰기(폴더로 연 사진)·다른 이름으로 저장(JPG/PNG/WebP)
  · 일괄 편집: 크기·보정·필터·액자·글자 워터마크({date} 촬영일)·로고를 여러 장에 한 번에 → 폴더 또는 ZIP
  · 페이지(콜라주): 틀 31가지, 칸 안에서 위치·확대·회전, 여백·간격·둥글기·원형/하트 칸·배경(그라데이션·흐린 사진)

  · 이름 바꾸기: {date}(촬영 날짜)·{n}(번호)·{name}·{camera} 규칙, 찾아 바꾸기, 미리보기, 되돌리기
  · 한계: HEIC·RAW는 열 수 없습니다(HEIC는 Plus에서). 얼굴 찾기는 없습니다. 파일 이름 바꾸기는 Chrome·Edge에서 폴더를 열 때만 됩니다.

자주 묻는 질문
────────────────────────────────────────
Q. 파일이 인터넷으로 올라가나요?
A. 아니요. 모든 처리는 내 컴퓨터의 브라우저 안에서만 이루어집니다.

Q. 저장할 때 위치를 묻지 않고 '다운로드' 폴더로 들어가요.
A. 브라우저 설정 → 다운로드 → '다운로드 전에 각 파일의 저장 위치 확인'을 켜세요.
   (Chrome·Edge에서는 보통 저장 위치를 고르는 창이 먼저 뜹니다.)

Q. HANAI Zip에서 '폴더에 풀기'가 안 돼요.
A. Chrome·Edge에서만 됩니다. 다른 브라우저에서는 '파일별 다운로드'를 쓰세요.

Q. HANAI Song 재생목록이 사라졌어요.
A. 환경 설정의 '재생목록 기억'이 켜져 있어야 합니다. 브라우저의 방문 기록·
   사이트 데이터를 지우면 함께 지워집니다.

— HANAI(HAN + AI)의 이름·디자인은 자체 제작이며, 이스트소프트 알툴즈·한글과컴퓨터 제품과는 관계가 없습니다.
